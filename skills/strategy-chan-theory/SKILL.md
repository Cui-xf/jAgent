# 策略 Skill：缠论（Chan Theory / Zen Channel Theory）

> 类别：B / 策略战法 · category=framework · 核心理念：1 严进 · 2 趋势 · 3 效率 · 4 买点偏好

## 适用场景

- 用户明确要求"用缠论分析"或"看一下买卖点 / 背驰 / 中枢"。
- 震荡市（中枢结构清晰）或强趋势启动 / 末段（背驰判定）。
- 本策略偏结构化思维，适合对"买点级别"和"仓位大小"有要求的决策场景。

## 必需数据

通过 `skill(name)` 依次加载：

1. 日线历史 K 线（窗口 ≥ 60 个交易日；周线若可用一并取，用于做级别共振）
2. 技术指标与趋势评分（必须拿到 MACD 的 DIF/DEA/柱状数据）
3. 实时行情（现价用于判断当下位于哪一段 / 是否触发买卖点）
4. 新闻舆情（辅助验证背驰信号；若出现利空需降级）

## 核心框架：分型 → 笔 → 线段 → 中枢 → 趋势

### 1. 价格结构识别
- 从历史 K 线里识别近期的高低点序列。
- 判定当前形态：
  - **震荡中枢**：≥ 1 个中枢，价格反复于中枢区间。
  - **趋势段**：连续 3 个同级别中枢沿同一方向递进。
- 标注最近一个中枢的上沿 / 下沿价位。

### 2. 背驰判断（最高优先级信号）
- **顶背驰**：价格创新高但 MACD 红柱面积缩小 / DIF 不创新高 → 卖出 / 减仓。
- **底背驰**：价格创新低但 MACD 绿柱面积缩小 / DIF 不创新低 → 买入 / 加仓。
- 背驰成立的前提是"同级别"——日线背驰只对日线级别操作有意义。

### 3. 买卖点判定
- **一买（最强）**：下跌趋势末段，最后一个中枢出现底背驰。仓位可重（≥ 30%）。
- **二买**：离开下跌中枢后的首次回调不破中枢高点。仓位中（20-30%）。
- **三买**：中枢震荡后向上突破，且回踩不回中枢内部。仓位中（20-30%）。
- **一卖 / 二卖 / 三卖**：镜像结构，触发减仓 / 清仓。
- 未达买卖点 → 明确写"暂无明确买卖点"，不强行给买入建议。

### 4. 级别共振
- 日线买卖点 + 周线同方向 → 信号最强，仓位可上限。
- 仅日线级别 → 仓位保守。
- 日线和周线矛盾（日买周卖）→ 小仓位试探或观望。

## 输出要求

- `strategy_used = "strategy-chan-theory"`
- `signal_type` 必须是以下之一："一买"/"二买"/"三买"/"一卖"/"二卖"/"三卖"/
  "中枢震荡无明确买卖点"/"趋势延续"。
- `technical_analysis` 中需新增字段语义：
  - `chan_structure`："上涨趋势" / "下跌趋势" / "中枢震荡"
  - `chan_divergence`："顶背驰" / "底背驰" / "无"
  - `chan_signal`：同 `signal_type`
- `battle_plan.sniper_points`：
  - `ideal_buy` = 买点对应价（一买贴近背驰低点 / 二三买贴近中枢边界）
  - `stop_loss` = 买入时设前低；若是二三买，设中枢下沿
  - `take_profit` = 下一级中枢上沿 / 前高
- `buy_reason` 中必须标明"缠论 X 买 / X 背驰"与对应级别（日 / 周）。

## 评分调整建议

| 情形 | sentiment_score |
|---|---|
| 底背驰 + 一买 | +15 |
| 二买 / 三买 + 日线周线共振 | +12 |
| 二买 / 三买 仅日线 | +8 |
| 中枢震荡无明确方向 | 维持基线（50-60） |
| 顶背驰 / 趋势向下 | -15（改为减仓 / 卖出） |
| 背驰成立但出现重大利空 | -8（降低置信） |

## 典型结论模板

- "日线最后一跌底背驰成立，构成一买，中枢下沿 X 元为止损，目标看上一级中枢上沿 Y 元。"
- "日线二买，回踩中枢上沿 X 元即理想买入价；周线同步向上，可放大仓位。"
- "当前处于日线中枢震荡，缠论下无明确买卖点，建议观望等待突破 / 回落出信号。"
