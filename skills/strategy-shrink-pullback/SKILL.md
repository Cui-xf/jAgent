# 策略 Skill：缩量回踩（Shrink Volume Pullback）

> 类别：B / 策略战法 · category=trend · 核心理念：1 严进 · 2 趋势 · 4 买点偏好

## 适用场景

- 已经确认处于上升趋势的股票，出现**短期回调**。
- 目标：在趋势延续前的低位吸货，而不是突破追涨。
- 典型信号："多头排列 + 缩量 + 回到 MA5/MA10 附近"。

## 必需数据

通过 `skill(name)` 依次加载并执行下列数据类 skill：

1. 实时行情（当前价 / 量比 / 换手率）
2. 日线历史 K 线（窗口 ≥ 30 个交易日，用于算回调幅度与量能对比）
3. 技术指标与趋势评分（需 MA5/MA10/MA20、`volume_status`、`bias_ma5/10`）
4. 筹码分布（获利比例 / 集中度）
5. 新闻舆情（近 3 日 risk_check 维度优先）

## 判定框架

### 1. 前提：必须是上升趋势
- MA5 ≥ MA10 ≥ MA20 多头排列。
- 最近 20 个交易日累计涨幅 > 5%。
- 不满足前提 → 直接放弃本策略，提示用户"当前无缩量回踩结构"。

### 2. 回踩检测
- 当前价落在 MA5 附近（误差 ≤ 1%）或 MA10 附近（误差 ≤ 2%）。
- 回调幅度 ≤ 近期高点的 7%（超过视为深度回调，不属于本策略范畴）。
- 回调期间 3-5 日平均成交量 < 近 5 日均量的 70%（缩量特征）。
- `volume_status` 应返回"缩量"或"平量偏缩"。

### 3. 反弹信号
- 当日或昨日出现小阳线守住均线支撑。
- MA5 乖离率 < 2% — 最佳买入区间。
- RSI 从 40-50 附近回升（未超买）。

### 4. 风险排查
- 近 3 日无利空新闻。
- 筹码分布健康：获利比例 50-80%、集中度 `concentration_90 ≤ 0.2`。
- 板块整体未跌破 MA20。

## 输出要求

- `strategy_used = "strategy-shrink-pullback"`
- `signal_type = "缩量回踩 MA5" / "缩量回踩 MA10"`
- `battle_plan.sniper_points`：
  - `ideal_buy` = MA5 水平
  - `secondary_buy` = MA10 水平
  - `stop_loss` = MA20 水平（跌破即破坏结构）
  - `take_profit` = 近期高点 / 箱体上沿
- `buy_reason` 必须注明"缩量回踩"并引用当日量比、bias_ma5、MA 位置等数据。

## 评分调整建议

| 情形 | sentiment_score |
|---|---|
| 缩量回踩 MA5（bias_ma5 < 1%，量 < 0.7 倍均量） | +10 |
| 缩量回踩 MA10（量 < 0.6 倍均量） | +8 |
| 回踩当日已出现小阳反包 | +5 |
| 回踩至 MA20 但量未缩 | -5（非理想结构） |
| 出现利空 / 跌破 MA20 | -12，改为观望 |

## 典型结论模板

- "多头趋势中缩量回踩 MA5（量比 0.65），RSI 企稳回升，给出小仓位试探买入信号。"
- "趋势完好但回调仍放量，尚未出现缩量特征，建议等待量能衰减到 0.7 倍以下再介入。"
- "回踩时跌破 MA20 且量能未缩 → 结构破坏，本策略不适用，改为观望。"
